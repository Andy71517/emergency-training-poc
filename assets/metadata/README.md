# Asset Metadata

Future asset metadata can live here.

Useful metadata may include the source tool or model, prompt or source reference, creation date, license/provenance notes, checks, reviewer, review status, and promoted file checksum.

For the first future environmental-object candidate, track it as a wooden chair. Useful notes would include intended scale, collision shape, mass assumptions, material assumptions, and whether it is only visual or ready for physics testing.
