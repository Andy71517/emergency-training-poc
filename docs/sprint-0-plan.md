# Sprint 0 Plan

## Goal

Remove ambiguity before implementation by defining the smallest vertical slice and its contracts.

## Work items

1. Establish repository boundaries and explicit non-goals.
2. Define trainee action, scenario state, validation result, and session message schemas.
3. Define one deterministic smoke-inhalation-room toy scenario and matching POC rules.
4. Record architectural decisions about determinism, ownership, contracts, and validation limits.
5. Reserve backend, script, Unreal, log, and asset locations without implementing them.
6. Review schemas/examples and use them as fixtures for the next sprint.

## Exit criteria

- All required files are present and parseable.
- Current versus future responsibilities are unambiguous.
- The next sprint can implement the loop without selecting a network, AI, sensor, or rendering architecture.
