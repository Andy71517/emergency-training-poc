# Current POC scope

Reviewed October 28, 2026. See [current status](current-status.md) for evidence
levels and [full vision](full-project-vision.md) for the wider goal.

## Implemented

- Local FastAPI/React studio with private local configuration and persistent
  SQLite room jobs, assets, history, replay and recoverable Trash.
- Real hosted ARC room planning, bounded validation, seeded layouts, previews and
  packages for the reviewed wooden-chair binding.
- Description-based chair/couch dispatch, pinned reference generation, Hunyuan
  shape/paint, fixed SSH/Slurm transport, recovery and result validation.
- Local Blender room worker and scoped Blender MCP asset preparation, conservative
  cleanup, convex decomposition, packed `.blend` and Unreal export package.
- Unreal 5.8 chair/room editor scripts, local bridge, Chaos batch reports and saved
  recording/encoding controls.
- Two deterministic YAML session scenarios with ordered WebSocket actions,
  rule findings, JSONL logs, replay and instructor review.
- Separate legacy fixture authoring/revision approval and browser primitive physics lab.

Implementation is not the same as live acceptance: the first automated ARC couch,
generic Unreal furniture import/cooking and live recording remain open checks.

## Outside the current accepted workflow

- Mixed-furniture room planning, asset lookup/footprints and coordinated Blender/Unreal bindings.
- Arbitrary semantic mesh reconstruction or guaranteed repair of missing/fused parts.
- Full trainee gameplay or a connected Unreal trainee WebSocket client.
- Real-time AI adaptation, clinical/protocol authority or validated trainee scoring.
- Live sensors, mannequin integration, projection mapping and multi-site networking.
- Production authentication, multi-user access, cloud hosting and field deployment.

## Acceptance rule

Keep each result traceable to its prompt, plan/request, revisions, scheduler evidence
and files. Review actual visual/geometry/collision output before reuse. Treat engine
observations separately from rule conformance and training validity. Never substitute
a chair for an unsupported furniture request or treat a saved request as a GPU result.
