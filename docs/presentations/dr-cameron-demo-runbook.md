# Dr. Cameron demo guide

Use the [current run-of-show](final-demo-run-of-show.md) and eight-slide
[deck](project-overview-slides.md). Documentation checkpoint: October 28, 2026.

The main message is that natural-language planning, reviewed chair rooms and native
asset preparation now have concrete implementation/evidence, while live automatic
couch generation and mixed-furniture environments still have explicit next checks.

## Rehearse

1. Install/build from `main` and run `python scripts/run_web_demo.py --port 8772`.
2. Open a saved room batch and inspect every output you intend to show.
3. If using Unreal, open the accepted project, save work and connect its local
   editor bridge. Rehearse fixed actions before the audience joins.
4. Keep the new asset connection result visible without exposing settings or keys.
5. Rehearse the deterministic session/review fallback through **Legacy POC tools**
   or `python scripts/run_menu_demo.py --fast`.

Do not regenerate a model merely for the presentation. Do not present the synthetic
MCP fixture as the couch or a package preflight as engine cooking. First live
recording remains unverified; use only inspected media and label its origin.
